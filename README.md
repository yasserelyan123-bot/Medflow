# ClinicFlow — نسخة نهائية جاهزة للرفع

## الملفات (3 بس، ارفعهم كلهم في نفس المكان)

```
index.html
app.js
schema.sql
```

## الخطوات

1. **امسح كل الملفات القديمة** من الريبو على GitHub (استخدم زرار سلة المهملات 🗑️ على كل ملف).
2. **ارفع الـ 3 ملفات دول** بنفس الأسماء دي بالظبط، في نفس المكان (الجذر الرئيسي للريبو، أو مجلد واحد لو الإعدادات كده — المهم يكونوا مع بعض).
3. لو لسه ما شغّلتش `schema.sql` جوه **Supabase → SQL Editor → Run**، اعملها الآن.
4. افتح الموقع، واستنى ثواني قليلة.

## الجديد في النسخة دي

- لو الصفحة فضلت تحمّل أكتر من 8 ثواني، هتظهر رسالة توضح السبب المحتمل (بدل الصفحة البيضاء الصامتة).
- لو مكتبة Supabase أو app.js فشلوا يتحمّلوا من الإنترنت، هتظهر رسالة فورية بدل الانتظار.

لو ظهرت أي رسالة حمراء بعد الرفع، ابعت **نصها بالظبط** أو screenshot، وهنحل المشكلة المحددة اللي هتظهر.
